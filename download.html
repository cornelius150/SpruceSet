📋 安装说明

  1. 下载安装版或便携版
  2. 安装版：双击运行 .exe 文件，按提示安装
  3. 便携版：双击运行 .exe 文件即可启动
  4. 首次启动会创建数据文件，默认存储在 %APPDATA%\SpruceSet\ 目录
  5. 如安装过旧版本，请先卸载旧版再安装新版本

🔄 更新日志

1.6.1（当前版本）

  • 截图序号工具：新增属性面板，可调节序号的颜色和大小（滑块 8-48px）
  • 截图形状选中后可调粗细和颜色：选中矩形/椭圆/直线/箭头/画笔标注后，形状面板同步显示该标注的粗细和颜色，修改后实时更新
  • 截图箭头加粗：增大最小线宽和箭头头部尺寸，箭头更明显
  • 笔记工具栏下拉三角形加大：项目符号/编号库等组合按钮的下拉箭头从 8px 加大到 12px
  • 背景色按钮改版：参考文字颜色 A 按钮结构，背景色按钮改为图标 + 色块 + 下拉三角形三合一布局

1.6.0

  • 默认存储改为分层文件夹 .md：新建文档默认使用「分层文件夹结构中的多个 .md 文件」——每个节点一个纯文本 Markdown 文件，可用任意文本编辑器打开、可用 Git 管理；图片/表格/代码框等富文本以 Markdown 格式保存在文件内
  • 保护正式数据：版本升级不再自动删除正式数据文件（仅清理测试残留文档）
  • 编辑区右键菜单重做：完全换成通用编辑菜单——撤销/重做/剪切/复制/粘贴/删除/全选/插入表情符号/更改大小写/剪切复制粘贴纯文本/行操作/格式化/插入/执行代码/删除行尾空格/查找/替换（含二级子菜单与禁用态）
  • 存储类型对话框：默认选中「分层文件夹 .md」，保存时直接选择目录

1.5.9

  • 编号库：OneNote 风格 25 种编号样式（数字/字母/罗马/中文数字/带圈/序数词/天干地支/英文单词等），编号列表按钮新增下拉样式库
  • 截图完成只复制剪贴板：完成后不再自动插入笔记，在笔记中 Ctrl+V 或右键粘贴即可（长截图同样）
  • 渐变箭头：箭头改为从小变大的实心渐变箭头（细尾→粗杆→三角头）
  • 截图标注全面可调：文字标注选中后可调字号/颜色（属性面板 + 右下角控制点）；画笔/涂鸦笔四角控制点缩放笔迹；拖出选区松手也能正确完成绘制
  • 截图面板位置：形状面板与文字属性面板移到工具栏下方，不再遮挡选区
  • 背景颜色修复：修复背景颜色只能设置黄色的问题，现支持全部颜色
  • 节点图标区分：添加节点与添加子节点工具栏图标区分（加号 / 分支符号）

1.5.8

  • 面板跟随按钮：字体/字号/颜色/项目符号面板弹在各自按钮正下方，不再出现在页面左上角
